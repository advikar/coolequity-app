[advikar/coolequity](https://github.com/advikar/coolequity), kept for reference: the original
brief and spec, demo and video scripts, red-team and UI reviews, product-readiness and delivery
plans, the redesign notes (`REDESIGN.md`, formerly `app/REDESIGN.md`) and the pitch deck
(`deck/`). They describe the project as it was on that branch and are not maintained.
